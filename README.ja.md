# duo-claude

[English](README) | [한국어](README.ko) | **日本語** | [中文](README.zh-CN)

Claude Code 向けのデュオリンゴ風復習スキルです。Claude が作業のひとまとまりを終えると、その作業のキーワードで4択問題を出し、間違えた問題は間隔反復のスケジュールで再出題します。問題は韓国語で出ます。

## インストール

```sh
git clone https://github.com/Bum-Boo/duo-claude ~/.claude/skills/duo-claude
```

Python 3 が必要です(標準ライブラリのみ)。スキルを読み込むため Claude Code を再起動してください。

## 使い方

| コマンド | 動作 |
| --- | --- |
| `/duo-claude` | オンにする。これまでの作業ですぐ出題し、以降は作業のまとまりが終わるたびに1~2問出します。 |
| `/duo-claude off` | このセッションでオフにする。 |
| `/duo-claude wiki [keyword]` | コードではなく自分のウィキ/ノートから出題。ノート検索・読み取りツール(ウィキ MCP など)か指定したノートフォルダが必要です。 |
| `/duo-claude review` | 復習の時期が来た問題のみ。 |
| `/duo-claude stats` | 総数、復習待ち、よく間違えるキーワード。 |

作業の途中では割り込まず、些細な修正はスキップします。オン/オフの状態は会話内にのみあるため、新しいセッションでは `/duo-claude` をもう一度実行してください。

## 復習の仕組み

問題は `~/.claude/quiz/items.jsonl` に保存されます(初回使用時に作成)。ライトナー式の箱1~5、間隔は1・3・7・14・30日で、間違えると箱1に戻ります。保存は `quiz_store.py`(`due`、`add`、`grade`、`stats`)が担当します。

## メモ

- ウィキの問題は Claude が実際に読んだノートからのみ作り、根拠ノートを併記します。
- 秘密情報や個人情報は問題にも保存先にも入れません。
